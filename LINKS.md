# Bhargava Junior College — all links

The site runs locally with `npm run dev` at **http://localhost:3000** (not hosted online yet).
When it is deployed, replace `http://localhost:3000` with the live address.

- **GitHub repository:** https://github.com/doddasurendra/Bhargava-junior-College
- **Supabase project:** https://nkhpahcmldfuwydeglml.supabase.co (dashboard: https://supabase.com/dashboard/project/nkhpahcmldfuwydeglml)

## Project files
- `README.md` — what's built, how to run, setup
- `AUDIT_REPORT.md` — checklist status (PASS / PARTIAL / MISSING) with evidence
- `supabase/migrations/` — database schema · `supabase/seed_sample_leads.sql` — 60 sample leads
- `.env.example` — every setting the site reads (copy to `.env.local`; never commit keys)
